Requirements to a telescope science-planning application

ContextContributionApproachEvidenceOutcome

The context

The project concerns a telescope science-plan system. Its requirements needed to be expressed as system scope, user interactions, application structure, and implementable behavior.

My contribution

Designed and documented system requirements using Use Case, Activity, Sequence, and Class diagrams, and developed and deployed a web application using Java, Spring Boot, Docker, and Render.

From problem to implementation

  1. Requirements → design

    Documented business and technical requirements through complementary UML views: Use Case, Activity, Sequence, and Class diagrams.

  2. Design → implementation

    Implemented the web application with Java and Spring Boot, with Docker and Render used for deployment.

Scope & credits

This is an academic team project. The contribution described here follows the existing résumé; the linked repository documents the wider project. “Gemini” refers to the telescope science-plan system.
