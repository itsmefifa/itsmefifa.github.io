Automatic grading assessment of cocoa seeds

From user requirements to a computer-vision prototype

The context

The project explores automated support for cocoa seed grading through image recognition, taking manual assessment as the use-case context.

My contribution

Analyzed user requirements, implemented YOLOv5 and YOLOv8 models, and evaluated model performance while translating the problem into a working AI prototype.

From problem to implementation

  1. Define the use case

    Connected user requirements with an image-recognition prototype for cocoa seed grading.

  2. Prototype and evaluate

    Implemented YOLOv5 and YOLOv8 and evaluated model performance within the final-year project.

Scope & credits

Academic project at Mahidol ICT / MVIT Research Lab. The collage shows the project team and sample visual output; it is not a standalone performance evaluation.

    Outcome & validation

    A working AI prototype in an undergraduate final-year project. The available portfolio material does not establish a production deployment or provide a benchmark suitable for a quantified improvement claim.

    Reading the evidence
